# Content v3 playground

In this repository:

```bash
npm install
npm run dev:prepare
npm run dev:v3
```

- URL: http://localhost:3000
- App: `playgrounds/content-v3`
- Pages: `/` (pass-in), `/auto-fetch`, `/props` (parameter matrix)

Logo: `/logo.png` in the playground header.
