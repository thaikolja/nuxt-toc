# Content v2 playground

```bash
npm install
npm run dev:prepare
npm run dev:v2
```

- URL: http://localhost:3001
- App: `playgrounds/content-v2`
- Pages: `/`, `/auto-fetch`, `/props`

Logo: `/logo.png`.
